# Santomi — трейлер «Магия подарков начинается здесь»

Отдельный проект Remotion: приложение и бэкенд Santomi он не трогает.

## Что внутри

| Путь | Назначение |
|---|---|
| `src/scenes/Scene01…07*.tsx` | семь сцен; каждая сама строит раскладку 9:16 или 16:9 |
| `src/components/` | телефон (`PhoneFrame`), титры (`Title`), световая волна, атмосфера, `Stage` (геометрия телефона, слои реального UI, коробка-подарок из двух рендеров, мешок с тростью) |
| `src/animations/` | кривые (`easeSoft` = `--ease-soft` приложения), камера 2.5D |
| `src/config/` | цвета бренда, шрифт, форматы, **таймлайн** (`timeline.ts`: окна сцен, звуковые метки, монтаж тизера) |
| `public/assets/3d/` | 3D-рендеры из `src/assets/3d` приложения + коробка и крышка от CEO |
| `public/assets/ui/` | реальные экраны демо-режима, снятые Playwright, и `ui-layout.json` (координаты элементов) |
| `public/audio/` | оригинальный звук, синтезированный кодом (`scripts/synth-audio.mjs`): без сэмплов и чужой музыки |
| `renders/` | готовые MP4 (в git не попадают) |

## Команды

```bash
npm install
npm run studio            # предпросмотр и правки в Remotion Studio
npm run audio             # пересобрать музыку и звуки
npm run render:vertical   # 1080×1920, 30 с
npm run render:horizontal # 1920×1080, 30 с
npm run render:teaser     # 1080×1920, 15 с
node scripts/qa.mjs renders/<файл>.mp4   # ffprobe, громкость, поиск чёрных кадров и вспышек
```

Переснять реальные экраны (из корня репозитория, поднимает demo-сборку):

```bash
npx playwright test --config=marketing/santomi-trailer/playwright.capture.config.ts
node marketing/santomi-trailer/scripts/cut-card.mjs
```

Во время съёмки (а не в коде приложения) применяются три правки: скрываются плашки «демо» и демо-тосты, размывается демо-ссылка `localhost/join/…` (имя бота не выдумываем), в пустой форме создания игры скрыты плейсхолдеры.

## Правила
- Шрифт: системный SF Pro там, где он есть, иначе Inter (OFL). Файлы SF Pro не встраиваются; рендер на Windows идёт в Inter.
- Музыку можно заменить лицензированным треком: положите файл в `public/audio/` и поменяйте путь в `Trailer.tsx`. Сильные доли трейлера: 6,0 с (пульс), 20,0–20,5 с (тишина), 22,83 с (открытие), 25,33 с (финал).
- «Скоро в Telegram» стоит, пока приложение не запущено. После запуска поменяйте строку в `Scene07Final.tsx`.
