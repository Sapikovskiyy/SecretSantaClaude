# Santomi — комплект передачи дизайна в Claude Code

## Содержимое
- `CLAUDE_CODE_IMPLEMENTATION_PROMPT_EN.md` — английское задание для Claude Code.
- `SANTOMI_UI_UX_TZ_RU.md` — полное русское ТЗ по 14 экранам, сценариям и проверкам.
- `MOTION_SPEC_RU.md` — отдельная подробная спецификация анимаций.
- `references/00_original_style_reference.png` — твой первоначальный референс с 3 экранами.
- `references/01_screens_01-04.png` — первые 4 экрана.
- `references/02_screens_05-08.png` — следующие 4 экрана.
- `references/03_screens_09-12.png` — следующие 4 экрана.
- `references/04_screens_13-14.png` — последние 2 экрана.

## Как использовать
1. Распакуй ZIP в отдельную папку или помести **содержимое** в проект `SecretSantaClaude` (например, `/design-handoff/`).
2. Не подменяй этим архивом исходники React; это дизайнерское ТЗ, а не готовый сайт.
3. Открой Claude Code с папкой проекта и дай ему файл `CLAUDE_CODE_IMPLEMENTATION_PROMPT_EN.md`. Укажи путь к каталогу `design-handoff/` со всеми референсами.
4. Сначала Claude должен сделать аудит и план, затем по твоему одобрению реализовать 4 ключевых экрана, показать скриншоты и получить одобрение визуального стиля.
5. После согласования всех 14 экранов — подключение настоящих функций и тестирование. Публикацию на Cloudflare только после отдельного одобрения.

## Примечания
Даты, цены, лица, ассортимент и платежи на картинках — демонстрационные элементы. В живом приложении они должны поступать из состояния приложения и серверных данных. Изображения-коллажи — наглядные образцы композиции, но **не** заменяют исходные 3D-ассеты и DOM-разметку.
